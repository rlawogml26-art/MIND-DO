# MEMO:RE 티켓 디자인 플러그인

피그마에서 티켓 디자인을 만들고, 앱이 읽는 디자인 파일(JSON + 그림)로 내보내는 플러그인입니다.
형식 설명은 AGENTS.md "티켓 디자인" 절을 따릅니다.

## 처음 한 번: 불러오기

1. 피그마 **데스크톱 앱**을 설치합니다 (웹 피그마에서는 불러올 수 없어요).
2. 레포 맨 위에서 빌드합니다.
   ```bash
   npm install
   npm run build -w shared
   npm run build -w tools/figma-plugin
   ```
3. 피그마에서 아무 파일이나 열고 메뉴 → 플러그인 → 개발 → **매니페스트에서 플러그인 가져오기**를 눌러 `tools/figma-plugin/manifest.json`을 고릅니다.
4. 이후에는 메뉴 → 플러그인 → 개발 → **MEMO:RE 티켓 디자인**으로 엽니다.

코드를 받아 새로 고친 뒤에는 2번 빌드만 다시 하면 됩니다.

## 디자인 만들기

1. 팀 파일 "MEMO:RE 티켓"에서 카테고리 페이지(티켓·폴라로이드·인생네컷·필름)를 엽니다.
2. 플러그인에서 **[빈 틀 만들기]** → 사진 1·2·3·4장 판(티켓 한 장씩)이 생깁니다.
3. (그림 배경을 쓸 때) **배경을 지운 투명 PNG**를 캔버스에 끌어다 놓고, 고른 채로 **[배경으로 깔기]** → 투명한 여백은 잘려 나가고 4장 판 맨 아래에 맞춰 깔립니다. 다시 누르면 이미지만 바뀌고, Ctrl+Z로 되돌릴 수 있어요.
4. 피그마 기능을 자유롭게 써서 꾸밉니다. 배경·장식·그림자·블러·그라데이션·투명도 모두 그대로 그림이 됩니다. 단, 섞기 모드(곱하기·오버레이 등)는 앱에서 사진과 섞이지 않아요.
5. 사진 자리(`photo-1`…)를 옮기고 모양을 바꿉니다. 네모·원·직선 다각형이 되고, 기울여도 됩니다.
6. 글자 자리(`text:…`)의 글꼴·크기·색을 정합니다. 글자에 넣은 테두리·그림자는 기본 효과로 들어갑니다.
7. 플러그인 창에 이름, id, 대표 색, 분위기 태그를 넣습니다. 카테고리는 페이지 이름에서 자동으로 정해집니다.
8. **[검사]** → 오류를 고칩니다. 항목을 누르면 그 레이어로 이동합니다.
9. **[내보내기]** → `<id>.zip`이 받아집니다.

## PR 올리기

```bash
git switch develop && git pull
git switch -c feature/design-<id>
# 레포 맨 위에 zip 압축 풀기 (파일이 제자리에 들어감)
npm run format
git add shared/src/designs frontend/assets/designs
git commit -m "feat: 티켓 디자인 <이름> 추가"
git push -u origin feature/design-<id>
```

PR이 올라가면 CI가 형식을 검사하고, 팀장이 앱에서 확인한 뒤 승인합니다.

## 레이어 이름 규칙

플러그인의 **[이름 붙이기]** 버튼을 쓰면 외울 필요가 없습니다.

| 이름                                | 뜻                                                                 |
| ----------------------------------- | ------------------------------------------------------------------ |
| `photo-1` ~ `photo-4`               | 사진 자리. 판마다 사진 수만큼, 티켓 판 바로 아래(그룹 밖)에 둡니다 |
| `text:title`                        | 공동 티켓 제목이 들어갈 자리                                       |
| `text:date`                         | 날짜                                                               |
| `text:groupName`                    | 그룹 이름                                                          |
| `text:participants`                 | 초대자 이름 목록 (초대자를 고르면 자동으로 채워짐)                 |
| `text:static`                       | 적힌 글자 그대로 (예: MEMO:RE)                                     |
| `text:title fallback="우리의 하루"` | 제목이 비었을 때 대신 쓸 문구                                      |
| `guide:…`                           | 안내용. 내보낼 때 빠집니다                                         |
| 그 밖의 이름                        | 전부 그림으로 구워집니다                                           |

## 알아 둘 것

- **그리는 순서**: 사진 자리보다 아래 레이어 → 아래 그림, 위 레이어 → 위 그림(테이프·빛 번짐 등). 사진 자리 사이에 낀 장식은 위로 올라갑니다.
- **공동 쪽**은 사진 수와 상관없이 같아야 합니다. 판마다 다르면 ticket-1 것을 씁니다.
- **글꼴**은 Noto Sans KR, Noto Serif KR, Nanum Pen Script, Black Han Sans만 됩니다 (앱에 들어 있는 글꼴).
- **사진 자리에 준 테두리·그림자**는 앱에서 나오지 않습니다. 액자는 사진 자리 아래에 따로 그리세요.
- 사진에는 필터·색을 입히지 않습니다.

## 배경 그림 준비하기

- **단색 바탕 위의 그림이면 그대로 넣으면 됩니다.** [배경으로 깔기]가 귀퉁이 색을 바탕으로 보고 알아서 지웁니다 (필름 구멍처럼 안쪽의 작은 구멍 포함). 바탕이 무늬·그라데이션이거나 티켓 색과 비슷하면 지우지 않고 알려 주니, 그때는 배경을 지운 투명 PNG를 넣어 주세요. 이미 투명한 PNG는 그대로 씁니다.
- **피그마 에이전트의 배경 제거는 최종 그림에 쓰지 마세요.** 결과 그림의 해상도를 크게 줄여서 앱에서 흐리게 보여요. 확인용으로만 쓰세요.
- 플러그인은 배경이 안 지워졌거나 해상도가 낮으면(150% 넘게 늘어나면) 경고합니다. [검사]에서도 같은 경고가 나와요.
- AI로 만들 때는 **글자·사진·사람이 없는 그림**만 만들게 합니다. 글자가 들어가면 모든 사람 티켓에 같은 글자가 박혀요. "스텁"처럼 영어로 쓰일 만한 단어는 문장에 넣지 마세요.
- 사진 틀(액자)은 그림에 넣지 말고 피그마에서 판마다 그립니다. 사진 수마다 틀 개수가 달라서요.
- 문장 예시:

  ```
  가로로 긴 티켓 이미지 한 장, 가로:세로 5:2 비율, 티켓이 이미지 가로를 거의 가득 채울 것.
  왼쪽 정확히 1/5 지점에 세로 점선 절취선이 있고, 그 왼쪽은 작은 조각, 오른쪽은 큰 본문.
  35mm 필름 스트립 느낌, 위아래 가장자리에 필름 구멍, 따뜻한 갈색과 크림색.
  본문 가운데는 넓게 비워 둘 것.
  어떤 글자나 숫자도 넣지 말 것. 사진, 사람, 로고 없음.
  단색 회색 배경.
  ```

- **남의 디자인을 그대로 따라 만들지 않습니다.** 직접 만들거나 AI로 생성한 이미지, 무료 소스만 씁니다.
