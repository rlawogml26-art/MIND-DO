# 개인 티켓 그리기·서버 연결 (앱)

중간 발표 시연 흐름(사진 → AI 초안 → 저장 → 일괄 보기)을 서버에 연결하면서 생긴 앱 코드 설명이다.
티켓을 그리거나 서버를 부르는 코드를 새로 만들기 전에 먼저 읽는다.

## 한눈에

| 파일                                | 하는 일                                                               |
| ----------------------------------- | --------------------------------------------------------------------- |
| `src/components/TicketRenderer.tsx` | 서버 디자인 값으로 개인 티켓(2:1) 한 장을 그린다                      |
| `src/lib/ticket-templates.ts`       | 템플릿별 사진 칸 좌표 (미소 님 시안)                                  |
| `src/lib/photo-upload.ts`           | 사진을 JPEG로 바꿔 S3에 직접 올리고 사진 키를 돌려준다                |
| `src/lib/api.ts`                    | 서버 호출 함수 (사진 업로드 정보, AI 초안, 개인 티켓 저장, 일괄 보기) |
| `src/types/form-data.d.ts`          | React Native의 FormData 파일 형식 타입                                |

## 티켓 그리기: `TicketRenderer`

서버는 티켓을 그림으로 주지 않고 값으로 준다.

```
templateId: "collage_grid"      ← AI가 고른 템플릿
backgroundColor: "#CE7A3B"      ← 서버가 사진 색으로 만든 배경색
사진: [사진1, 사진2, 사진3]       ← 순서대로, 1번이 대표 사진
```

`TicketRenderer`가 이 값을 받아 좌표대로 사진을 놓고, 배경을 칠하고, 템플릿 효과를 얹는다.

```tsx
<TicketRenderer photos={[{ uri }, { uri }]} design={design} width={너비} />
```

- 높이는 너비의 절반으로 자동 계산된다 (개인 티켓 2:1)
- `design`이 없거나 예전 형식이면 기본 템플릿·기본 배경색으로 그린다
- 쓰는 곳: AI 초안 01·02·03, 티켓 확인·발권 미리보기, 일괄 보기
- **티켓을 그려야 하면 새로 만들지 말고 이 컴포넌트를 쓴다**

템플릿별 효과 (시안 값)

| 템플릿         | 이름            | 효과                                                  |
| -------------- | --------------- | ----------------------------------------------------- |
| `blend_fade`   | 자연스러운 장면 | 사진 칸마다 맨 위 0% → 맨 아래 100% 배경색으로 흐려짐 |
| `collage_grid` | 감각적인 조합   | 효과 없음. 사진 사이 여백에 배경색이 보임             |
| `light_basic`  | 광원·색감·질감  | 사진 영역 하단 중앙에서 타원 빛(#FBC100, 60% → 10%)   |

공통 규칙: 사진은 칸을 꽉 채우고 가운데 기준으로 자름, 1번 사진이 맨 앞, 티켓 밖은 자름.

## 템플릿 좌표: `ticket-templates.ts`

- 미소 님 시안 표를 그대로 옮겼다. 템플릿 3종 × 사진 1~4장, 값은 티켓 크기 대비 %
- **템플릿 모양을 고치거나 템플릿을 늘릴 때는 이 파일만 바꾼다**
- 앱만 쓰는 값이라 `shared/`가 아니라 여기에 둔다 (서버는 좌표를 쓰지 않는다)

## 티켓 제작 화면의 서버 모드 (`TicketEditor.tsx`)

`TicketCreationScreen`에 `sharedTicketId`를 넘기면 서버 모드가 된다.

```
사진 고르기 → [초안 만들기] 사진 S3 업로드 → AI 초안 3개 → 01·02·03 고르기
→ 뒷면 메모 → 티켓 확인 → 서버에 저장 → 일괄 보기로 돌아감
```

- `sharedTicketId`를 안 넘기면 기존처럼 기기 임시 저장으로 동작한다 (기존 흐름 그대로)
- 그룹 화면의 일괄 보기에서 내 슬롯이 비어 있으면 "+ 내 티켓 만들기"로 서버 모드를 연다

서버 모드에서만 다른 규칙 (서버 명세 기준)

| 상황                       | 동작                                   | 이유                                           |
| -------------------------- | -------------------------------------- | ---------------------------------------------- |
| 다시 만들기                | 안내만 함                              | AI 초안은 일반 사용자 1인 1회                  |
| 꾸미기                     | 건너뜀                                 | 서버 디자인 형식이 지금 스티커·글자 0개만 받음 |
| 초안을 받은 뒤 사진만 바꿈 | AI를 다시 부르지 않고 사진만 다시 올림 | AI 초안 명세: 같은 디자인에 사진만 바뀐다      |
| 초안을 받은 뒤 나가기      | 확인 창                                | 초안은 서버에 저장되지 않아 다시 받을 수 없음  |
| 저장 전 검사               | 뒷면 메모 길이만                       | 날짜·제목은 공동 티켓에 이미 있음              |

01·02·03과 미리보기는 기존 `FramePreview`의 사진 영역 위에 `TicketRenderer`를 덮어 그린다.
그래서 화면 배치(절취선 쪽, 크기)는 기존 그대로다.

## 서버 호출 규칙

- 서버 주소와 요청은 `lib/api.ts`에만 둔다. **화면에서 `fetch`를 직접 쓰지 않는다**
- 응답은 `shared/`의 zod 스키마로 검사하고, 실패는 `ApiError`의 `code`로 판단한다 (문구로 판단하지 않는다)
- 사진 업로드는 `uploadTicketPhotos(공동 티켓 ID, 사진 주소들)` 하나로 한다
  - 모든 사진을 JPEG로 바꾸고, 서버 제한(10MB)을 넘을 때만 줄인다
  - 사진은 서버를 거치지 않고 S3에 직접 올라간다. 돌려받은 사진 키를 AI 초안·저장에 그대로 쓴다
- 사진 링크(서명 링크)는 앱에 저장하지 않는다. 만료되면 다시 조회한다

## 아직 안 된 것

코드에 `// 후속 Issue #번호` 주석으로 위치를 표시해 두었다.

- 꾸미기 서버 저장 (스티커·글자)
- VIP 재생성
- 홈 달력·보관함에 서버에 저장한 티켓 표시 (지금은 기기 임시 저장만 읽음)
- 사진 축소 기준(긴 변 2048px·화질 0.85) 팀 확정
